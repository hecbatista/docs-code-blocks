Docs Code Blocks

Works in any Google Doc. No setup needed.

``` Enter
New code block. Add a language to pick it: ```python, ```js, ```java. Otherwise it's detected.
``` or ⌘/CtrlEnter
Finish in the editor and insert the block. Esc cancels.
Tab / ShiftTab
Indent / dedent. New lines keep their indentation automatically.
CtrlShiftK
Turn selected text into a block, or edit the block your cursor is in.
Copy · Edit
Buttons on each block's label row. For Edit, click inside the block first.
